# OptiCore

Audit, restauration et optimisation de Windows pour le jeu (Minecraft en tête). Chaque réglage est
sauvegardé avant d'être appliqué, relu, et s'annule en un clic ; la sécurité de Windows n'est jamais
affaiblie.

Ce dépôt sert à distribuer les versions :
**[télécharger la dernière version](https://github.com/roblitchtv-dotcom/opticore/releases/latest)**
(installeur Windows `OptiCore_x.y.z_x64-setup.exe`).

Une fois installé, OptiCore se met à jour depuis ces releases. Chaque installeur publié est signé avec
la clé du projet, et OptiCore vérifie cette signature avant d'installer quoi que ce soit.

L'installeur n'a pas de certificat Windows : au premier lancement, SmartScreen peut afficher un
avertissement (« Informations complémentaires », puis « Exécuter quand même »).
